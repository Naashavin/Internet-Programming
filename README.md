# Internet Programming Lab Experiments

This repository contains clean, self-contained, university-level solutions for the Internet Programming (IP) Laboratory exercises.

## List of Experiments

### 1. [ExpNO_1.html](ExpNO_1.html) — Local Library Management System
- **Student / User Portal**: Book catalog search, borrow history, fine calculation (Rs. 5/day), year & semester-wise study material download, and student profile.
- **Librarian Admin Portal**: Inventory management (Add, Update, Delete books), issue book to student, return status & fine calculation, and upload study materials.

### 2. [ExpNO_2.html](ExpNO_2.html) — Hotel Room Booking Website
- **User / Guest Portal**: Room availability check and booking for 4 room types (*Single, Double, Deluxe, Suite*), booking history with 3-day advance notice rule for changing or cancelling bookings, reviews and ratings, and static info pages.
- **Administrator Portal**: Manage quantities and night prices for all 4 room types, change/cancel bookings, and modify static pages content.

### 3. [ExpNO_3.html](ExpNO_3.html) — Online Bus Ticket Booking System
- **Passenger / User Portal**: Bus search by route, date, and time; visual seat selection; passenger details & payment simulation; booking history with cancellation; and bus comments.
- **Administrator Portal**: Bus categories maintenance (*Volvo, Sleeper coach, etc.*), add/update bus information, user management, travel news updates, and report generation.

### 4. [ExpNO_4.html](ExpNO_4.html) — Online Train Reservation System
- **Passenger / User Portal**: Passenger authentication, search trains & seat availability with via-details, passenger details form, payment modes (online/offline), PNR status checker, cancellation with refund rules (75% refundable percentage), and printable ticket history.
- **Administrator Portal**: Admin login, train schedule maintenance (zone, class, and date-wise fares), payment ledger records, and refund processing.

### 5. [ExpNO_5.html](ExpNO_5.html) — Online Flight Reservation System
- **Passenger / User Portal**: Login, registration & forgot password utilities, search flight page by destination, date & class, seat selection and booking, payment gateway, my e-ticket page with print option, view booking status by reference, ticket cancellation, and customer feedback.
- **Administrator Portal**: Admin login, flight schedules & seat inventory management, and operational reporting (bookings and revenue analytics).

### 6. [ExpNO_6.html](ExpNO_6.html) — Online Cake Ordering System
- **Student / User Portal**: Register and login, search cake, filter by category (*Birthday, Wedding, Anniversary*), sub-category/flavor (*Chocolate, Red Velvet, Vanilla*) and price range, view cake list and descriptions, add to cart, customized order placement (size & personalized message on cake), manage shipping address, and track order shipping status.
- **Administrator Portal**: Admin login and logout, product inventory management (post cake details, flavor, price, description, and photo/icon), manage orders, update order status (*Baking, Quality Checked, Out for Delivery, Delivered*), and assign shipping location.
